# Risk-Reward Decision Making (Gamble filter)

Default: **avoid gambles**. A gamble is any option where the text suggests a
large loss is possible, the outcome is uncertain, or the option cuts corners,
hides a problem, bends rules or damages trust for a quick gain.

## Step 1: Is it a gamble?

Mark an option as a gamble if any of these apply:

- It could cost a lot of Health, Dignity, Network or Wealth.
- It defers, hides or shifts blame for a problem (this builds hidden risk
  that can surface later as a serious organisational consequence).
- Its result depends on luck or on someone else's reaction.

## Step 2: Is the gamble allowed?

Allow a gamble only if all of these hold:

1. The safer options cannot fix a real, current problem (for example a weak
   review is likely and no safe option raises Output enough).
2. No stat it could hurt is already in the warning zone.
3. There is time left to recover if it goes wrong (not the final months).
4. No gamble was taken recently. Space them out so losses cannot stack.

Never take an option that hides a problem or breaks trust, even when allowed
by the rules above. The hidden-risk cost is not visible until it is too late.

## Step 3: Record it

If a gamble is taken, say so in the `notes` so that `feedback-assessment`
can check the outcome and stop repeating it if it went badly.
